# 街角餐厅教学案例

直接在线体验或下载到本机，使用 Node.js 22 或以上运行：

```bash
node serve.mjs
```

打开终端打印的地址。不要直接双击 HTML，模块文件需要通过本机 HTTP 服务加载。

- `?stage=1`：最小循环，只经营简餐，不报废食材。
- `?stage=2`：菜单、价格、客流与库存损耗。
- `?stage=3`：设备、七天目标、纪念、存档与合成音效。

## 第一次操作

采购三次简餐食材，现金从 1000 变成 880、库存 15。点击开门，观察厨房与顾客，可暂停或加速。结算后查看收入、费用与流失，再进入下一天。

## 文件

- `core.mjs`：菜品、状态、采购、订单、结算、升级、存档校验。
- `ui.mjs`：按钮、界面、模拟时钟与声音。
- `style.css`：颜色、布局与状态样式。
- `assets.svg`：原创炉灶、桌子、顾客与菜品图标。
- `index.html`：页面结构。
- `serve.mjs`：本机预览服务，不需要线上部署。

## 边界

固定布局，接待与厨房岗位做了抽象，没有独立员工寻路、背景音乐、联网或云存档。起始规则用于教学，不是商业平衡结论。保存只支持非营业阶段，进度在本机；不同阶段使用不同存储键。

代码、矢量素材及程序合成声音按仓库 MIT 许可分发。上线前应测试目标设备、清点资源并检查平台当前要求。
