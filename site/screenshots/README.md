# 餐厅实机截图

这七张 PNG 均在 2026-10-18 通过浏览器实际操作 `examples/restaurant/` 截取，游戏代码对应提交 `1a44790`。截图没有用生成图片代替运行画面，也没有修改画面中的数字。部分图片仅裁取当前页面中的相关区域。

浏览器视口为 1280×720。操作依次使用采购、菜单、价格、开门、暂停、加速、下一天和设备购买按钮。加速只缩短等待，不改变游戏规则。截图来自简餐版与完整版两组经营安排；为获得清楚的构图，简餐账本按相同开局重放截取。不能把全部截图拼成同一次营业的记录。

| 文件 | 实际操作与画面 |
| --- | --- |
| `01-preparation.png` | 第一阶段，第 1 天采购简餐三次；现金 880，食材 15 份。 |
| `02-service.png` | 同一轮，第 66 个游戏内秒暂停；已服务 5 人，厨房做简餐，用餐区有顾客在吃、有人在等。 |
| `03-day-report.png` | 重放同一简餐开局，打烊时服务 15 人，收入 300，日利润 60；缺货与座位不足各流失 6 人。 |
| `04-menu-and-price.png` | 完整教学版的新一轮，第 1 天上架三道菜，准备 10 份简餐、5 份盖饭、5 份套餐，采用精品价。 |
| `07-price-report.png` | 上述三菜精品价菜单的打烊结果；收入 307，利润 19，现金变化 -53。 |
| `05-second-station.png` | 完整版第 3 天购买第二工位，在真实营业中截取双工位同时制作的画面。 |
| `06-seven-days.png` | 同一轮经营至第 7 天结束。画面中的账本数字为第 7 天数据，不是七天累计。 |

截图与案例中的原创素材采用本仓库 MIT 许可。`site/figures/asset-board.svg` 中的六种图形直接取自案例 `assets.svg`，可运行 `node scripts/figures.mjs` 重新生成。
